NetworkShare
WebDAV · Local Network · File Sharing

NetworkShare is an Android app for sharing device storage over a local network using WebDAV. It allows folders from internal storage or SD cards to be accessed directly from devices like Windows, Linux, or macOS without cables or cloud services.

  • Built-in HTTP WebDAV server running on a foreground service
  • Digest authentication support for protected file sharing
  • Share selected folder(s) or full storage
  • Supports most storage locations
  • Network management system for controlling trusted connections
  • Designed for continuous local network access and background operation

ClipSync
Cross-Platform · Clipboard Sync · Windows ↔ Android

ClipSync is a clipboard syncing app for Windows and Android that keeps copied text shared between both devices over a local network in real time.

  • Real-time clipboard syncing between Windows and Android
  • Connects through a lightweight HTTP server running on Windows
  • Android foreground service handles continuous background syncing
  • Overlay-based clipboard actions for Android compatibility
  • Built with Kotlin on Android and Python on Windows
